# FB-DB
FootBall DataBase is a CLI that harnesses the power of pro-football-reference.com to quickly get specific pieces of NFL data.

# Planned Features
- Scorigami: Check if a final score has ever happened in NFL History (thank you Jon Bois)
- Team Records: Check the W-L-T record for a specific team, with a flag to get the current season's record.
- Player Stats: Get specific or general stats for a specific player, with different stats depending on their playing position
- more...

# Purpose
As a personal project, this project has two main purposes for myself. First, this is my first project using the Go programming language which I have grown quite fond of. Secondly, this is also my first project where I am using web scraping to obtain specific data from websites.
